### 4. Limites de poder efetivamente computáveis

Com os números declarados, o que é computável sem inventar dados:

1. **Fator de N necessário sob `z ∝ √N`, mesmo efeito e `σ_sys = 0`:**
   - V2: `(5/0,177851)² ≈ 790,36`.
   - R-B: `(5/0,343377425)² ≈ 212,03`.

2. **Efeito de 4x eventos:**
   - `√4 = 2`.
   - V2: `2 × 0,177851 = 0,355702σ`.
   - R-B: `2 × 0,343377425 = 0,68675485σ`.
   - Para 5σ com 4x, seria necessário `z₁ ≥ 2,5σ`.

3. **Teto por sistemática compartilhada que não cai com N:**
   Se `σ_total(N) = √(σ_stat²/N + σ_sys²)` e `f = σ_sys/σ_total(atual)`, então `z_max = z₁/f`.
   Para `z_max ≥ 5`:
   - V2: `f ≤ 0,177851/5 = 0,0355702` → **3,56%**.
   - R-B: `f ≤ 0,343377425/5 = 0,068675485` → **6,87%**.
   Se a sistemática compartilhada for maior que isso, **nenhum N atinge 5σ**.

4. **Modelo de correlação intraclasse entre eventos:**
   Se `z_N = z₁√N / √(1+(N-1)ρ)`, o teto é `z∞ = z₁/√ρ`.
   Para `z∞ ≥ 5`:
   - V2: `ρ ≤ (0,177851/5)² ≈ 0,001265`.
   - R-B: `ρ ≤ (0,343377425/5)² ≈ 0,004716`.
   Ou seja, a correlação sistemática entre “eventos” precisaria ser menor que `~0,13%` (V2) ou `~0,47%` (R-B). Isso é extremamente restritivo; daí a necessidade de medir `ρ`, não postular.

5. **Combinação de dois canais:**
   Para estimativas `x` com covariância `Σ`, o combinador de mínimos quadrados é:
   `z_comb = (1ᵀΣ⁻¹x) / √(1ᵀΣ⁻¹1)`.
   Não usar `√(z₁²+z₂²)` sem verificar independência e mesma direção. Para D1 V3 e T11, o valor ingênuo é `≈ 4,218σ`; 5σ exigiria correlação negativa `ρ < -0,288`.

### 5. Nulidade, múltiplos testes e covariâncias

- **Nulidade por observável.** Eco: H0 de ausência de eco, rival GR/eco alternativo. Piso dos vazios: H0 LCDM raso, rival feedback bariônico. D1/T11: H0 é a escala declarada/rival cosmológico. U3: H0 de sobreposição local por ruído. Não existe um H0 único “GR β=0” para todos.
- **Trials.** Precisam ser pré-especificados por observável: templates de eco, time-slides, larguras de janela, escolha de void finder, cadeias MCMC, seleção H1/L1. Contar arquivos/hashes de strain como trials independentes é erro.
- **Bonferroni.** Válido sob dependência arbitrária; conservador. Para `m` testes, `α_fam = α/m` controla FWER. Holm é válido e mais poderoso sob dependência arbitrária; BH exige independência ou PRDS. A correção do meu erro: Bonferroni **não requer independência**.
- **Covariâncias.** H1/L1 do mesmo evento são correlacionados. Sistemáticas de template, calibração, whitening e janelamento podem ser compartilhadas. A matriz `Σ` deve ser medida ou modelada com justificação; não se pode somar sigmas nem tratar 4/4 como quatro eventos independentes.
- **Sistemática compartilhada.** Se não cai com N, impõe teto. A pergunta operacional é: qual fração do erro atual é sistemática compartilhada? Sem essa medida, o poder para 5σ não é computável.
