## 2. Prova escrita completa

### 2.0 Fatos auxiliares (todos elementares)

- **(F1)** p(1−p) > 0. *(0 < p e 1−p > 0; produto de positivos. Em particular a hipótese κ < p(1−p) é não-vacuosa e κ = 0 é permitido.)*
- **(F2)** (2p−1)² = 4p² − 4p + 1 = 1 − 4p(1−p); logo **0 ≤ (2p−1)² < 1** (a não-estrita: quadrado; a estrita: F1). *(Identidade por `ring`; as desigualdades por F1.)*
- **(F3)** s ≥ 0 ⟹ −2s ≤ 0 ⟹ **e^{−2s} ≤ e⁰ = 1**, e **e^{−2s} > 0**. *(Monotonicidade/estrita monotonicidade de exp; e^{−2s} < 1 sse s > 0. Em s = 0 vale igualdade.)*
- **(F4)** **0 ≤ 4κ e^{−2s} ≤ 4κ** para s ≥ 0. *(Primeira: 4κ ≥ 0 por κ ≥ 0, vezes F3 positiva. Segunda: F3 multiplicada por 4κ ≥ 0. Estrita < 4κ sse κ > 0 e s > 0.)*

### 2.1 Item (i): 0 ≤ r(s) < 1 para todo s ≥ 0 (s = 0 incluído)

**Cota inferior.** A(s) ≥ 0 *(soma de quadrado com termo ≥ 0, por F4)* ⟹ r(s) = √A(s) ≥ 0 *(a raiz real é não-negativa)*.

**Cota superior — cadeia completa de desigualdades:**

1. 4κ e^{−2s} ≤ 4κ *(F4, segunda parte; usa 4κ ≥ 0 — por isso hκ0 é hipótese)*;
2. (2p−1)² = 1 − 4p(1−p) *(F2)*;
3. 4κ < 4p(1−p) *(hipótese κ < p(1−p), multiplicada por 4 > 0; o lado direito é positivo por F1)*;
4. A(s) = (2p−1)² + 4κ e^{−2s} ≤ **(passo 1)** (2p−1)² + 4κ = **(passo 2)** 1 − 4p(1−p) + 4κ **< (passo 3)** 1;
5. 0 ≤ A(s) < 1 ⟹ r(s) = √A(s) < √1 = 1 *(raiz estritamente crescente em [0,∞); √1 = 1)*. ∎

**Em s = 0:** e⁰ = 1, A(0) = (2p−1)² + 4κ < 1 pelo mesmo passo 4 — **a desigualdade estrita não depende de s > 0; ela vem de κ < p(1−p)**. F3 vira igualdade em s = 0 e nada quebra.

### 2.2 Item (ii): r antítona em [0,∞) (estrita se κ > 0; constante se κ = 0)

Sejam 0 ≤ s ≤ t. Cadeia:

1. −2t ≤ −2s ⟹ e^{−2t} ≤ e^{−2s} *(exp crescente)*;
2. ⟹ 4κ e^{−2t} ≤ 4κ e^{−2s} *(multiplicar por 4κ ≥ 0 — F4)*;
3. ⟹ A(t) ≤ A(s) *(somar (2p−1)² aos dois lados)*;
4. ⟹ r(t) ≤ r(s) *(raiz crescente)*. ∎

**Estrita:** se κ > 0 e s < t, os passos 1–2 são estritos *(exp estritamente crescente; 4κ > 0)*, e o passo 4 preserva estrita *(raiz estritamente crescente)*: r(t) < r(s). **Se κ = 0:** A(s) = (2p−1)² para todo s, logo r ≡ √((2p−1)²) = |2p−1|, constante — antítona (não-estrita), como enunciado.

**Corolário (não pedido; usado em (v)):** **r(s) ≥ |2p−1|** — na verdade para todo s real: A(s) ≥ (2p−1)² *(F4, primeira parte)* ⟹ √A(s) ≥ √((2p−1)²) = |2p−1| *(raiz crescente; √(u²) = |u|)*. Note que este corolário **não usa s ≥ 0**.

### 2.3 Item (iii): S monótona (crescente) em [0,∞)

**Controle de domínio (onde a âncora vale):** por (i), 0 ≤ r(s) < 1 ⟹ ½ ≤ x(s) = (1+r(s))/2 < 1, i.e., **x(s) ∈ Icc ½ 1** para todo s ≥ 0. *(É aqui que (i) trabalha: a âncora `binEntropy_strictAntiOn` vale em Icc ½ 1, e não fora dele. Na mathlib, `binEntropy` é total — fora de [0,1] ela usa `Real.log` de |·| — logo o controle de argumento é parte da prova, não ornamento.)*

Sejam 0 ≤ s ≤ t. Por (ii), r(t) ≤ r(s) ⟹ **x(t) ≤ x(s)**, com x(s), x(t) ∈ Icc ½ 1. Como binEntropy é **estritamente antítona em Icc ½ 1** (âncora), em particular antítona: x(t) ≤ x(s) ⟹ binEntropy(x(t)) ≥ binEntropy(x(s)), i.e., **S(s) ≤ S(t)**. ∎

**Estrita:** κ > 0 e s < t ⟹ x(t) < x(s) ⟹ *(antítona estrita)* S(s) < S(t): S estritamente crescente. **Se κ = 0:** S ≡ binEntropy((1+|2p−1|)/2) = binEntropy(p) *(por (iv), abaixo)* — constante.

### 2.4 Item (iv): binEntropy((1+|2p−1|)/2) = binEntropy(p) — vale para todo p real, sem hipóteses

O argumento é o **máximo** do par {p, 1−p}: como |2p−1| = |p − (1−p)|,

- **Caso p ≥ ½:** |2p−1| = 2p−1 ⟹ (1+|2p−1|)/2 = p. Identidade trivial.
- **Caso p ≤ ½:** |2p−1| = 1−2p ⟹ (1+|2p−1|)/2 = 1−p, e binEntropy(1−p) = binEntropy(p) pela âncora **`binEntropy_one_sub`**.
- **p = ½** pertence aos dois ramos; ambos dão binEntropy(½). ∎

### 2.5 Item (v): D(s) ≥ 0 e D antítona em [0,∞)

**A desigualdade-chave S(s) ≤ binEntropy(p), passo a passo:**

1. 4κ e^{−2s} ≥ 0 *(F4)* ⟹ (2p−1)² ≤ A(s) ⟹ **|2p−1| = √((2p−1)²) ≤ √A(s) = r(s)** *(raiz crescente; √(u²) = |u|)*;
2. −1 < 2p−1 < 1 *(de 0 < p < 1)* ⟹ **|2p−1| < 1**, e |2p−1| ≥ 0 ⟹ **x₀ := (1+|2p−1|)/2 ∈ [½, 1)**;
3. **x(s) ∈ [½, 1)** *(item (i), como em (iii))*;
4. **x₀ ≤ x(s)** *(passo 1; somar 1 e dividir por 2 preservam ≤)*;
5. x₀, x(s) ∈ Icc ½ 1 e x₀ ≤ x(s) ⟹ **S(s) = binEntropy(x(s)) ≤ binEntropy(x₀)** *(binEntropy antítona em Icc ½ 1 — a âncora estrita passada à antítona)*;
6. binEntropy(x₀) = binEntropy(p) *(item (iv))*;
7. Logo **S(s) ≤ binEntropy(p)** para todo s ≥ 0 ⟺ **D(s) = binEntropy(p) − S(s) ≥ 0**. ∎

**Antítona:** s ≤ t ⟹ S(s) ≤ S(t) *(item (iii))* ⟹ binEntropy(p) − S(s) ≥ binEntropy(p) − S(t), i.e., **D(s) ≥ D(t)**. ∎ **Estrita:** κ > 0 e s < t ⟹ D(s) > D(t).

### 2.6 Fronteiras (pedidas explicitamente)

| fronteira | por que está no domínio | o que acontece |
|---|---|---|
| **s = 0** | `Ici 0` o inclui | e⁰ = 1; A(0) = (2p−1)² + 4κ < 1 **pela hipótese κ < p(1−p)** (a estrita não vem de s > 0). (i)–(v) valem; D(0) ≥ 0, e D(0) = 0 sse κ = 0 *(opcional: injetividade da antítona estrita no intervalo)*. |
| **κ = 0** | hκ0 admite; F1 garante 0 < p(1−p), logo a hipótese estrita κ < p(1−p) é satisfeita | r ≡ \|2p−1\| ∈ [0,1) constante; (ii) vale na forma não-estrita; S ≡ binEntropy(p); **D ≡ 0**. As formas estritas foram enunciadas **condicionais a κ > 0** — nada quebra. |
| **p = ½** | 0 < p < 1 o inclui | (2p−1)² = 0; hipótese vira κ < ¼; A(s) = 4κ e^{−2s} ≤ 4κ < 1; r(s) = 2√κ·e^{−s} ∈ [0,1) *(√κ < ½ por raiz estrita; √(e^{−2s}) = e^{−s} pois e^{−s} > 0 — forma fechada opcional, candidatos no Lean)*; (iv) fecha nos dois ramos; x₀ = ½; S(s) ≤ binEntropy(½) = binEntropy(p). |

*Observação (não usada, portanto não dependência):* x₀ = (1+|2p−1|)/2 = max(p, 1−p) é o ponto de Icc ½ 1 mais próximo de ½; a prova de (v) nunca precisou do valor de binEntropy em ponto algum — só da monotonicidade e da simetria. É exatamente a rota pedida.
