## 1. Resposta direta à pergunta única

A prova mínima tem **cinco passos** e **nenhum axioma novo**: a premissa de uma única amostra `s0 > 0` se propaga por indução aos múltiplos `n·s0` (S1–S3); o limite contínuo da fonte (`flowTendsToFamily_of_finiteDimensional`, linhas 428–479) se restringe, por composição — não por postulação — à subsequência `n·s0 → ∞` (S4); e a unicidade de limite em espaço `T2` identifica `l x` com `l (reading H x)` (S5). A hipótese `0 < s0` é usada em **exatamente um** ponto (S4) e é **necessária**, como mostra o controle da seção 5.

**Mapa de uso das hipóteses** (pedido: hipóteses precisas):

| hipótese | onde entra |
|---|---|
| `[RCLike 𝕜]`, espaço normado/produto interno, `CompleteSpace`, `FiniteDimensional` | S4 (via limite da fonte) |
| `IsSelfAdjoint H`, forma não-negativa `∀ x, 0 ≤ re ⟪x, H x⟫` | S4 (via limite da fonte) |
| `l` contínua | S5 (transporte do limite por `l`) |
| `Y` espaço `T2` | S5 (unicidade do limite) |
| `0 < s0` | **somente S4** (`atTop_mul_const`) |
| `hcons : ∀ x, l (T H s0 x) = l x` | **somente S3** (propagação indutiva) |

**O que NÃO se assume** (conforme a ordem): (i) conservação para todo `s` — deriva-se nos múltiplos de `s0` (S3) e estende-se a todo `s` no corolário da seção 4; (ii) o limite discreto — deriva-se do limite contínuo da fonte por composição de `Tendsto` (S4); (iii) qualquer identidade de `reading` além das da fonte.

**Dependências reutilizadas da fonte** `[FONTE/REAL na fonte]`:
- `flowTendsToFamily_of_finiteDimensional` (linhas 428–479) — o limite espectral contínuo;
- `reading_T H hH s x : reading H (T H s x) = reading H x` (usada na fonte, linhas 330 e 358) — só no corolário;
- as definições `T`, `flow`, `reading`, `FlowTendsToFamily` (unfolds conforme a fonte; não reproduzidos nos trechos — trato como `[FONTE]`).

```lean
theorem T_zero_apply (H : E →L[𝕜] E) (x : E) : T H 0 x = x := by
  rw [T, flow]                 -- [CANDIDATO: unfold conforme a fonte]
  simp                         -- esperado: exp 𝕜 (0 • H) = exp 𝕜 0 = 1; [CANDIDATO: `NormedSpace.exp_zero`]

    [CANDIDATO: se a fonte já expõe `T_add`/`flow_add`, apagar e usar o da fonte.] -/
theorem T_add (H : E →L[𝕜] E) (s t : ℝ) (x : E) :
    T H (s + t) x = T H s (T H t x) := by
  rw [T, T, T, flow, flow, flow]
  push_cast
  rw [← smul_add]
  -- exp(A + B) = exp A * exp B quando A e B comutam;
  -- os dois somandos são múltiplos escalares do MESMO H.
  rw [NormedSpace.exp_add_of_commute]          -- [CANDIDATO: nome exato]
  · rw [ContinuousLinearMap.mul_apply]
  · exact (Commute.refl H).smul_left _ |>.smul_right _   -- [CANDIDATO: formação da Commute]

/-- (S2) O semigrupo discreto: (T s₀)^[n] = T (n·s₀). Por indução — não é axioma. -/
theorem T_iterate_eq_T_nsmul (H : E →L[𝕜] E) (s0 : ℝ) (n : ℕ) :
    ∀ x : E, (T H s0)^[n] x = T H ((n : ℝ) * s0) x := by
  induction n with
  | zero =>
      intro x
      rw [Function.iterate_zero_apply,       -- [CANDIDATO]
          Nat.cast_zero, zero_mul, T_zero_apply]
  | succ n ih =>
      intro x
      rw [Function.iterate_succ_apply',      -- [CANDIDATO]
          ih x, Nat.cast_succ]
      have h : ((n : ℝ) + 1) * s0 = (n : ℝ) * s0 + s0 := by ring
      rw [h, T_add]

/-- (S3a) Conservação propagada às potências de T s₀ — derivada de UMA amostra. -/
theorem conserved_iterate (H : E →L[𝕜] E) (l : E → Y) {s0 : ℝ}
    (hcons : ∀ x, l (T H s0 x) = l x) (n : ℕ) :
    ∀ x : E, l ((T H s0)^[n] x) = l x := by
  induction n with
  | zero => intro x; rw [Function.iterate_zero_apply]
  | succ n ih =>
      intro x
      rw [Function.iterate_succ_apply', hcons, ih]

/-- (S3) Conservação nos múltiplos inteiros de s₀. -/
theorem conserved_iterated (H : E →L[𝕜] E) (l : E → Y) (s0 : ℝ)
    (hcons : ∀ x, l (T H s0 x) = l x) (n : ℕ) (x : E) :
    l (T H ((n : ℝ) * s0) x) = l x := by
  rw [← T_iterate_eq_T_nsmul H s0 n x]
  exact conserved_iterate H l s0 hcons n x

/-- (S4) O limite discreto — DERIVADO do limite contínuo da fonte por composição;
    não é postulado. Único ponto que usa `0 < s0`. -/

  have hcont : Tendsto (fun s : ℝ => T H s x) atTop (𝓝 (reading H x)) :=
    flowTendsToFamily_of_finiteDimensional H hH hpos x   -- [FONTE: linhas 428–479;
                                                          --  aplicar a x conforme a def
                                                          --  de `FlowTendsToFamily`]
  have hmul : Tendsto (fun n : ℕ => (n : ℝ) * s0) atTop atTop :=
    tendsto_natCast_atTop_atTop.atTop_mul_const hs0      -- [CANDIDATO: nomes exatos]
  exact hcont.comp hmul

/-- (S5) ★ A RECÍPROCA DE UMA AMOSTRA: de `l (T s₀ x) = l x` com s₀ > 0
    segue `l x = l (reading H x)`. -/
theorem conserved_of_single_sample (H : E →L[𝕜] E) (hH : IsSelfAdjoint H)
    (hpos : ∀ x, 0 ≤ RCLike.re ⟪x, H x⟫_𝕜)
    (l : E → Y) (hl : Continuous l)
    (s0 : ℝ) (hs0 : 0 < s0)
    (hcons : ∀ x, l (T H s0 x) = l x) (x : E) :
    l x = l (reading H x) := by
  -- a sequência n ↦ l (T (n·s₀) x) é constante em l x …
  have hconst : (fun n : ℕ => l (T H ((n : ℝ) * s0) x)) = fun _ => l x :=
    funext fun n => conserved_iterated H l s0 hcons n x
  have hseq : Tendsto (fun n : ℕ => l (T H ((n : ℝ) * s0) x)) atTop (𝓝 (l x)) := by
    rw [hconst]; exact tendsto_const_nhds
  -- … e tende a l (reading H x) por transporte do limite (S4) através de l contínua
  have hlim : Tendsto (fun n : ℕ => l (T H ((n : ℝ) * s0) x)) atTop
      (𝓝 (l (reading H x))) := by
    simpa [Function.comp_apply] using
      (hl.tendsto _).comp (tendsto_discrete_sample H hH hpos s0 hs0 x)  -- [CANDIDATO: `Continuous.tendsto`]
  -- T2: limites são únicos
  exact tendsto_nhds_unique hseq hlim        -- [CANDIDATO: nome exato; usa NeBot de atTop em ℕ]

end SingleSample
end SingleSampleConverse
```

## 3. As provas em prosa (o conteúdo matemático)

**S1 — adição.** `T H r := exp(−(r:𝕜) • H)`. Como `−((s+t):𝕜) • H = (−(s:𝕜)) • H + (−(t:𝕜)) • H` e os dois somandos são múltiplos escalares do mesmo `H` (logo comutam), a exponencial de elementos que comutam em álgebra de Banach dá `exp(A+B) = exp A · exp B`; aplicando a `x`, `(A * B) x = A (B x)`. ∎

**S2 — semigrupo discreto.** Base: `f^[0] x = x` e `T (0·s0) = T 0 = 1`. Passo: `f^[n+1] x = T s0 (f^[n] x) = T s0 (T (n·s0) x) = T (n·s0 + s0) x` por S1, e `(n+1)·s0 = n·s0 + s0`. ∎ (Isto descarrega o pedido explícito `T(s0)^[n] = T(n·s0)`.)

**S3 — conservação iterada.** Base: `l (f^[0] x) = l x`. Passo: `l (f^[n+1] x) = l (T s0 (f^[n] x)) = l (f^[n] x) = l x`, o primeiro passo por `hcons`, o segundo pela hipótese de indução. Reescrita por S2 leva aos múltiplos `n·s0`. ∎ — **Derivada da premissa de uma amostra; não assumida para todo `s`.**

**S4 — limite discreto.** `n ↦ (n:ℝ)·s0` tende a `atTop` porque `s0 > 0`. Compor com `Tendsto (fun s => T H s x) atTop (𝓝 (reading H x))` da fonte. ∎ — **O limite discreto é composição de `Tendsto`, não axioma.**

**S5 — unicidade.** A sequência `n ↦ l (T (n·s0) x)` é constante `= l x` (S3), logo converge a `l x`; por `hl : Continuous l` composta com S4, converge a `l (reading H x)`. Em `T2`, limites são únicos: `l x = l (reading H x)`. ∎

## 4. Corolário: a premissa de uma amostra implica a conservação global

```lean
/-- Recíproca plena a partir de UMA amostra: as duas premissas são equivalentes.
    A direção de volta vale para TODO s e não usa `hs0`. -/
theorem conserved_iff_factors_of_single_sample (H : E →L[𝕜] E) (hH : IsSelfAdjoint H)
    (hpos : ∀ x, 0 ≤ RCLike.re ⟪x, H x⟫_𝕜)
    (l : E → Y) (hl : Continuous l) (s0 : ℝ) (hs0 : 0 < s0) :
    (∀ x, l (T H s0 x) = l x) ↔ ∀ x, l x = l (reading H x) := by
  refine ⟨fun h x => conserved_of_single_sample H hH hpos l hl s0 hs0 h x,
          fun h s x => ?_⟩
  calc l (T H s x) = l (reading H (T H s x)) := h _
    _ = l (reading H x) := by rw [reading_T H hH s x]   -- [FONTE: linhas 330/358]
    _ = l x := (h x).symm
```

Leitura: composto com `conserved_iff_factors_T` da fonte, obtém-se a cadeia de equivalências **(uma amostra `s0 > 0`) ⟺ (todo `s ≥ 0`) ⟺ (`l = l ∘ reading H`)** — a premissa mais fraca possível já descarrega a recíproca inteira. A invocação posterior do teorema da fonte é, portanto, opcional; o caminho S1–S5 é mais curto.

## 5. Controle negativo `s0 = 0` — a conclusão falha

**Matemática fechada (à mão, sem computação):** tome `E = ℝ`, `H = 1 : ℝ →L[ℝ] ℝ` (auto-adjunto; `re ⟪x, 1 x⟫ = x² ≥ 0`, forma não-negativa — de fato positiva; `ker 1 = ⊥`, logo `reading 1 x = 0` para todo `x`), `l = id : ℝ → ℝ` (contínua; `ℝ` é `T2`). Com `s0 = 0`: `T 1 0 = exp 0 = 1`, então a premissa `∀ x, l (T 1 0 x) = l x` **vale**. Mas em `x = 1`: `l x = 1` e `l (reading 1 x) = l 0 = 0`. Logo `l x ≠ l (reading H x)`: a conclusão **falha**. A hipótese `0 < s0` é, portanto, necessária — e o controle localiza a necessidade exatamente em S4 (`n·s0` com `s0 = 0` é a sequência constante `0`, que não tende a `atTop`). Consistência cruzada: com `s0 > 0` e este `H`, a premissa `hcons` exigiria `e^(−s0)·x = x` para todo `x`, o que é falso — o teorema corretamente não se aplica.

Esqueleto do controle (mais esquemático; `[CANDIDATO]` nos unfolds):

```lean
theorem control_zero_sample_fails :
```
