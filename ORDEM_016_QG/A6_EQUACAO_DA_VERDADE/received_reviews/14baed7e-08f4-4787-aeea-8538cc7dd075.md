## 1. Desenho mínimo do D2 para os dois blocos

O harness D2 deve ser escrito pela bancada, sem importar nem copiar o script da V1. Para os blocos abaixo:

1. **Bloco A — sinal de \(dS/ds\) por aritmética de intervalos.**
   - Usar `mpmath.iv`.
   - No mínimo 64 pontos em \(s \in [0,10]\). No código candidato: 65 pontos.
   - Incluir pares \((p,c)\) com:
     - \(p=\tfrac12\), \(c \neq 0\);
     - \(|c|^2 = 0{,}99\,p(1-p)\).
   - Exigir domínio estrito \(0 < r < 1\), com \(r\) o raio de Bloch/autovalor:
     \[
     \lambda_\pm = \frac{1\pm r}{2}.
     \]
   - Calcular
     \[
     S(\rho_s) = -\lambda_+\ln\lambda_+ - \lambda_-\ln\lambda_-,
     \qquad
     \frac{dS}{ds} = -\operatorname{atanh}(r)\frac{dr}{ds}.
     \]
   - Verificar sinal estrito e uniforme nos pontos amostrados. Se o intervalo cruzar zero, o veredito é `INCONCLUSIVE`, não `PASS`.

2. **Bloco B — identidade de entropia relativa.**
   - Calcular o lado esquerdo por logaritmo matricial:
     \[
     D(\rho_s\|\sigma) = \operatorname{Tr}\rho_s(\log\rho_s - \log\sigma).
     \]
   - Calcular o lado direito por entropias escalares:
     \[
     S(\sigma) - S(\rho_s).
     \]
   - Avaliar com 50+ dígitos. Tolerância: `1e-40`.
   - Degenerescência e \(\kappa=0\): ramos separados, ver §4.

3. **Anti-circularidade.**
   - O lado esquerdo da identidade **não** pode ser definido como \(S(\sigma)-S(\rho_s)\).
   - O lado direito **não** pode ser obtido do lado esquerdo.
   - Para o sinal de \(dS/ds\), não usar a identidade de entropia relativa para inferir o sinal.
   - A fórmula simbólica de \(dS/ds\) e a avaliação intervalar são o alvo; a identidade relativa é check separado.

4. **Grade finita não é prova universal.**
   - O código abaixo faz verificação pontual/amostral.
   - Se o critério exigir o contínuo \(s\in[0,10]\), é necessário cobrir intervalos por subdivisão com `mpmath.iv` ou prova simbólica de sinal. A grade de 65 pontos, sozinha, deve ser rotulada `REAL_NUMERICO_EM_PONTOS`, não teorema.

## 2. Código candidato — Bloco A: sinal de \(dS/ds\) via `mpmath.iv`

```python
# d2_bloco_A_sinal_dSds.py
# CANDIDATO — NÃO EXECUTADO.
# A bancada deve declarar qualquer semente antes de rodar. Este bloco é determinístico.

import mpmath as mp
from mpmath import iv
import sympy as sp

mp.mp.dps = 60

# ------------------------------------------------------------------
# Modelo simbólico de testemunha.
# ATENÇÃO: a receita D2 manda usar a evolução de §6.
# Aqui se usa a solução de projeção ρ̇ = -(I-E)ρ com E pinçamento diagonal:
#   c_s = c * exp(-s)
# Se a fonte D2 tiver outra expressão para c_s/r_s, substituir r_expr.
# ------------------------------------------------------------------
p, c, s = sp.symbols('p c s', real=True, nonnegative=True)

def r_expr(pv, cv, sv):
    return sp.sqrt((2*pv - 1)**2 + 4*cv**2*sp.exp(-2*sv))

def dSds_expr(pv, cv, sv):
    r = r_expr(pv, cv, sv)
    dr = sp.diff(r, sv)
    return -sp.Rational(1, 2)*sp.log((1 + r)/(1 - r))*dr

# ------------------------------------------------------------------
# Pontos (p, c). Inclui p=1/2, c!=0 e |c|^2 = 0.99 p(1-p).
# ------------------------------------------------------------------
def pontos_pc():
    pts = []
    for p0 in [
        sp.Rational(1, 2),
        sp.Rational(1, 10),
        sp.Rational(1, 4),
        sp.Rational(3, 4),
        sp.Rational(9, 10),
    ]:
        c2 = sp.Rational(99, 100) * p0 * (1 - p0)
        pts.append((p0, sp.sqrt(c2)))  # |c|^2 = 0.99 p(1-p)

    # caso adicional explícito: p=1/2, c != 0
    pts.append((sp.Rational(1, 2), sp.Rational(1, 10)))
    return pts

def s_points_mpf(n=65):
    return [mp.mpf(10) * mp.mpf(k) / mp.mpf(n - 1) for k in range(n)]

def mp_from_exact(x):
    if isinstance(x, sp.Rational):
        return mp.mpf(x.p) / mp.mpf(x.q)
    return mp.mpf(str(sp.N(x, 80)))

def iv_narrow(x_mpf, rad='1e-45'):
    rad = mp.mpf(rad)
    return iv.mpf([str(x_mpf - rad), str(x_mpf + rad)])

def check_sinal_dSds():
    signs = set()

    for p0, c0 in pontos_pc():
        p_mpf = mp_from_exact(p0)
        c_mpf = mp_from_exact(c0)

        for s_mpf in s_points_mpf(65):
            pI = iv_narrow(p_mpf)
            cI = iv_narrow(c_mpf)
            sI = iv_narrow(s_mpf)

            # r^2 = (2p-1)^2 + 4 |c|^2 exp(-2s)
            r2 = (2*pI - 1)**2 + 4*cI**2*iv.exp(-2*sI)
            r = iv.sqrt(r2)

            # domínio estrito r > 0, r < 1
            if r.a <= 0 or r.b >= 1:
                raise AssertionError(f"r fora de (0,1): {r}")

            # para c_s = c exp(-s):
            # dr/ds = -4 c^2 exp(-2s) / r
            dr = -4*cI**2*iv.exp(-2*sI) / r

            # dS/ds = -atanh(r) dr/ds
            #        = -(1/2) log((1+r)/(1-r)) dr/ds
            dS = -iv.log((1 + r)/(1 - r)) / 2 * dr

            if dS.a > 0:
                signs.add(+1)
            elif dS.b < 0:
                signs.add(-1)
            else:
                raise AssertionError(f"intervalo de dS/ds cruza zero: {dS}")

    if len(signs) != 1:
        raise AssertionError(f"sinais inconsistentes: {signs}")

    return signs.pop()  # +1 ou -1; a bancada compara com o esperado de D2
```

**Observação honesta:** a expressão de `dr` acima corresponde à testemunha \(c_s=c e^{-s}\). Se a receita D2 usar outra forma para \(r_s\), trocar `r_expr`, `dr`, e a avaliação intervalar correspondente. Não inferir isso de V1.

## 3. Código candidato — Bloco B: identidade de entropia relativa

```python
# d2_bloco_B_entropia_relativa.py
# CANDIDATO — NÃO EXECUTADO.
# Usa autodecomposição exata/spectral via sympy e avaliação mpmath a 50+ dígitos.

import mpmath as mp
import sympy as sp

mp.mp.dps = 60
TOL = mp.mpf('1e-40')

p, c, s = sp.symbols('p c s', real=True, nonnegative=True)

def r_expr(pv, cv, sv):
    return sp.sqrt((2*pv - 1)**2 + 4*cv**2*sp.exp(-2*sv))

def xlogx(x):
    if sp.simplify(x) == 0:
        return sp.Integer(0)
    return x * sp.log(x)

def log_from_evals(M, lam_minus, lam_plus, kappa=None):
    """
    log(M) = log(lam_plus) P_plus + log(lam_minus) P_minus
    para M Hermitiana 2x2.
    Se lam_plus == lam_minus, M = lam * I, logo log(M) = log(lam) I.
    kappa=0 deve ser tratado por ramo analítico da receita D2.
    """
    if kappa is not None and sp.simplify(kappa) == 0:
        raise NotImplementedError(
            "kappa=0: inserir o ramo analítico da receita D2; não inventar aqui."
        )

    if sp.simplify(lam_plus - lam_minus) == 0:
        return sp.log(lam_plus) * sp.eye(2)

    I = sp.eye(2)
    P_plus = (M - lam_minus * I) / (lam_plus - lam_minus)
    P_minus = (M - lam_plus * I) / (lam_minus - lam_plus)
    return sp.log(lam_plus) * P_plus + sp.log(lam_minus) * P_minus

def s_points_sym(n=65):
    return [sp.Rational(10 * k, n - 1) for k in range(n)]

def pontos_pc():
    pts = []
    for p0 in [
        sp.Rational(1, 2),
        sp.Rational(1, 10),
        sp.Rational(1, 4),
        sp.Rational(3, 4),
        sp.Rational(9, 10),
    ]:
        c2 = sp.Rational(99, 100) * p0 * (1 - p0)
        pts.append((p0, sp.sqrt(c2)))
    pts.append((sp.Rational(1, 2), sp.Rational(1, 10)))
    return pts

def check_identidade_entropica():
    max_res = mp.mpf(0)
    worst = None

    for p0, c0 in pontos_pc():
        for s0 in s_points_sym(65):
            r0 = r_expr(p0, c0, s0)

            # ρ_s = [[p, c exp(-s)], [c exp(-s), 1-p]]
            rho0 = sp.Matrix([
                [p0, c0 * sp.exp(-s0)],
                [c0 * sp.exp(-s0), 1 - p0],
            ])

            # σ = diag(p, 1-p)  (ponto fixo do pinçamento; conferir na receita D2)
            sigma0 = sp.Matrix([
                [p0, 0],
                [0, 1 - p0],
            ])

            # Autovalores de ρ_s: (1 ± r)/2
            lam_rho_minus = (1 - r0) / 2
            lam_rho_plus = (1 + r0) / 2

            # LHS: D(ρ||σ) = Tr ρ (log ρ - log σ)
            logrho0 = log_from_evals(rho0, lam_rho_minus, lam_rho_plus)
            logsigma0 = log_from_evals(sigma0, p0, 1 - p0)
            lhs0 = (rho0 * (logrho0 - logsigma0)).trace()

            # RHS: S(σ) - S(ρ_s), por entropias escalares independentes
            S_sigma0 = -xlogx(p0) - xlogx(1 - p0)
            S_rho0 = -xlogx(lam_rho_minus) - xlogx(lam_rho_plus)
            rhs0 = S_sigma0 - S_rho0

            lhs_val = mp.mpf(str(sp.N(sp.re(lhs0), 80)))
            rhs_val = mp.mpf(str(sp.N(sp.re(rhs0), 80)))

            res = abs(lhs_val - rhs_val)
            if res > max_res:
                max_res = res
                worst = (p0, c0, s0)

            if res > TOL:
                raise AssertionError(
                    f"resíduo {res} > {TOL} em p={p0}, c={c0}, s={s0}"
                )

    return max_res, worst
```

## 4. Degenerescência e \(\kappa=0\)

### Autovalores degenerados
Para uma matriz Hermitiana \(2\times2\):

- Se \(\lambda_+ = \lambda_-\), então \(M=\lambda I\).
- Nesse caso:
  \[
  \log M = \log(\lambda) I.
  \]
- O código implementa esse ramo em `log_from_evals`.
- Não usar autovetores genéricos quando há degenerescência; eles são não únicos e podem introduzir erro artificial.
- No caso \(p=\tfrac12\), \(\sigma=\tfrac12 I\) é degenerado. O ramo trata isso separadamente.
- No caso \(r=0\), \(\rho=\tfrac12 I\). O domínio pedido é \(r>0\), mas o ramo está previsto para segurança.

### \(\kappa=0\)
- Se a receita D2 usar um parâmetro \(\kappa\), o caso \(\kappa=0\) deve ser resolvido por **ramo analítico da própria receita**, antes de qualquer diagonalização genérica.
- Não inferir \(\kappa=0\) de V1 nem inventar limite.
- No código candidato, o ramo está marcado como `NotImplementedError` de propósito: a fórmula deve ser colada da fonte D2.
- Se a receita não fornecer \(\kappa\), o caso não é aplicável e deve ser registrado como `NAO_APLICAVEL`, não como `PASS`.

## 5. Como impedir teste circular

| risco | mitigação no D2 |
|---|---|
| Definir \(D(\rho\|\sigma)=S(\sigma)-S(\rho)\) e depois “verificar” a mesma igualdade | LHS é calculado por \(\operatorname{Tr}\rho(\log\rho-\log\sigma)\), usando log matricial. RHS é calculado por \(S(\sigma)-S(\rho)\) via entropias escalares. |
| Usar \(\log\sigma\) diagonal como atalho e reaproveitar a mesma conta no RHS | O LHS usa a matriz \(\log\sigma\) obtida por decomposição espectral; o RHS usa apenas autovalores de \(\sigma\). A igualdade é testada, não assumida. |
| Inferir o sinal de \(dS/ds\) a partir da identidade entrópica | Bloco A é independente: usa \(r\), \(\lambda_\pm\), \(dS/ds\) e `mpmath.iv`. Bloco B é outro check. |
