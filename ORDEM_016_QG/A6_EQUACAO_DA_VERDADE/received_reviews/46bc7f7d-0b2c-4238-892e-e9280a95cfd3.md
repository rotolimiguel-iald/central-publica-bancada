## 1. Enunciado

Sejam `𝕜 ∈ {ℝ, ℂ}` (RCLike), `E` espaço com produto interno de dimensão finita `n`, `H : E →L[𝕜] E` autoadjunto com forma não-negativa, `γ > 0`, e a **hipótese do gap sobre o mesmo objeto `eigenvalues` da base**:

```
hgap : ∀ i, ev i = 0 ∨ γ ≤ ev i        (ev := hsym.eigenvalues hn)
```

Então, para todo `x : E` e todo `s ≥ 0`, com `P := reading H` (projeção ortogonal sobre `ker H`):

```
‖T H s x − P x‖ ≤ exp(−s·γ) · ‖x − P x‖.
```

**Observação sobre hipóteses:** `hpos` (não-negatividade) é mantida por fidelidade ao enunciado da unidade; a estimativa consome apenas `hgap` e `hs`. Com `γ > 0`, `hgap` já força `ev i ≥ 0` fora do kernel. Mostro `hev_nn` como verificação de coerência (mesmo padrão da fonte, ll. 449–454).

## 2. Prova escrita

Seja `b` a base ortonormal de autovetores (`hsym.eigenvectorBasis hn`), com `H (b i) = (ev i : 𝕜) • b i`. Seja `z := {i | ev i = 0}`.

**(F1)** `b i ∈ ker H ⟺ ev i = 0` — pois `H (b i) = ev i • b i` e `b i ≠ 0` (ortonormal).

**(F2)** Todo `w ∈ ker H` se escreve como `w = ∑_{i∈z} cᵢ bᵢ` — expandindo `H w = 0` na base, `cᵢ · ev i = 0` para todo `i`; fora de `z`, `ev i ≠ 0`, logo `cᵢ = 0`.

**(F3)** `P x = ∑_{i∈z} cᵢ bᵢ` (`cᵢ = b.repr x i`) — o RHS está em `ker H` por (F1) e fechamento de subespaço; `x − RHS ∈ (ker H)ᗮ`: para `w ∈ ker H`, por (F2), `⟪w, x − RHS⟫ = Σᵢ conj(cᵢʷ)·(cᵢ − 𝟙_z cᵢ) = 0` (em `z` o fator da direita zera; fora de `z`, `cᵢʷ = 0`). Pela **unicidade da decomposição ortogonal** (`u − P x ∈ K ⊓ Kᗮ = ⊥`), o RHS é `P x`.

**(F4)** `T H s (b i) = e^{−s·ev i} • b i` — é `T_apply_eigen` das fontes.

**Cálculo.** Por linearidade de `T H s` e (F3)–(F4):

```
T_s x − P x = Σᵢ dᵢ • bᵢ,   dᵢ := (e^{−s·ev i} − 𝟙_z(i)) · cᵢ.
```

Para `i ∈ z`: `dᵢ = (e⁰ − 1)cᵢ = 0`. Para `i ∉ z`: `ev i ≥ γ` (hipótese do gap) e, como `s ≥ 0` e `exp` é monótona, `e^{−s·ev i} ≤ e^{−sγ}`.

**Parseval** (isometria `b.repr` + `EuclideanSpace.norm_eq`):

```
‖T_s x − P x‖² = Σ_{i∉z} e^{−2s·ev i}·|cᵢ|²  ≤  e^{−2sγ}·Σ_{i∉z}|cᵢ|²  =  e^{−2sγ}·‖x − P x‖²,
```

onde a última igualdade usa que, por (F3), `x − P x = Σ_{i∉z} cᵢ bᵢ`. Tomando raízes (ambos os lados não-negativos; `√(e^{−2sγ}) = e^{−sγ}`):

```
‖T_s x − P x‖ ≤ e^{−sγ}·‖x − P x‖.   ∎
```

**Casos degenerados, sem forçar autovalor positivo:**
- **`ker H = ⊤` (H = 0):** `z = Fin n`; `T_s x = x = P x`; ambos os lados `0`; vale `0 ≤ 0`.
- **Dimensão zero (`n = 0`):** `Fin 0` vazio; todas as somas são vazias; `x = 0`; vale `0 ≤ 0`. Em Lean, metas sobre `i : Fin 0` fecham por `Fin.elim0`; as somas vazias fecham as demais.
- **`ker H = ⊥`:** `z = ∅`; a cota vale com todos os termos presentes.

**Separação da igualdade de norma de operador.** Para `s > 0`: se `z ≠ univ`, `‖T_s − P‖ = e^{−s·m}` com `m := min{ev i : i ∉ z}` (atingido em `x = b i` do modo mínimo); se `z = univ`, `‖T_s − P‖ = 0 < e^{−sγ}`. Logo `‖T_s − P‖ = e^{−sγ}` para todo `s ≥ 0` **sse** o complemento é não-nulo **e** o gap é **atingido** (`∃ i ∉ z, ev i = γ`). A V1 medir `‖T_s − P‖ = e^{−6s}` no exemplo é coerente: ali `γ = 6` é o mínimo positivo. A desigualdade pontual implica a cota de norma (pois `‖x − P x‖ ≤ ‖x‖`), mas a **igualdade** é outro enunciado, fora do escopo desta unidade — esqueleto separado abaixo.

**Por que Parseval e não a triangular.** A triangular termo a termo daria `‖T_s x − P x‖ ≤ e^{−sγ}·Σ_{i∉z}|cᵢ|`; Cauchy–Schwarz então introduz `Σ|cᵢ| ≤ √n·√(Σ|cᵢ|²) = √n·‖x − P x‖` — o fator `√n` destrói a constante `1`. A receita (isometria `b.repr` + `EuclideanSpace.norm_eq`) mantém a cota **dentro** da soma de quadrados.

/-- ★ A6: taxa pontual do fluxo dissipativo em dimensão finita. -/
theorem norm_T_sub_reading_le_exp {n : ℕ} (H : E →L[𝕜] E) (hH : IsSelfAdjoint H)
    (hpos : ∀ x, 0 ≤ RCLike.re ⟪x, H x⟫_𝕜) (hn : Module.finrank 𝕜 E = n)
    {γ : ℝ} (hγ : 0 < γ)
    (hgap : ∀ i, hH.isSymmetric.eigenvalues hn i = 0 ∨ γ ≤ hH.isSymmetric.eigenvalues hn i)
    (x : E) {s : ℝ} (hs : 0 ≤ s) :
    ‖T H s x - reading H x‖ ≤ Real.exp (-(s * γ)) * ‖x - reading H x‖ := by
  set hsym : (H : E →ₗ[𝕜] E).IsSymmetric := hH.isSymmetric with hhsym
  set b := hsym.eigenvectorBasis hn with hb
  set ev := hsym.eigenvalues hn with hev
  have hv : ∀ i, H (b i) = (ev i : 𝕜) • b i := fun i => hsym.apply_eigenvectorBasis hn i
  -- coerência: autovalores não-negativos (padrão da fonte T20, ll. 449–454)
  have hev_nn : ∀ i, 0 ≤ ev i := by
    intro i
    have h1 := hpos (b i)
    rw [hv i, inner_smul_right, RCLike.re_ofReal_mul, inner_self_eq_norm_sq,
      b.orthonormal.1 i] at h1
    norm_num at h1
    exact h1
  have hb_inner : ∀ i, ⟪b i, b i⟫_𝕜 = 1 := by
    intro i
    rw [inner_self_eq_norm_sq, b.orthonormal.1 i]
    norm_num
  set z := Finset.univ.filter (fun i => ev i = 0) with hz
  have hzmem : ∀ {i}, i ∈ z ↔ ev i = 0 := by
    intro i
    rw [hz, Finset.mem_filter]
    exact and_iff_right (Finset.mem_univ i)
  -- (F1)
  have hF1 : ∀ i, b i ∈ H.ker ↔ ev i = 0 := by
    intro i
    rw [LinearMap.mem_ker, hv i]
    constructor
    · intro h
      rcases smul_eq_zero.1 h with h0 | hb0
      · exact_mod_cast h0
      · exfalso
        have h1 := b.orthonormal.1 i
        rw [hb0, norm_zero] at h1
        exact one_ne_zero h1
    · intro h
      rw [h]
      simp
  -- expansão de H w na base
  have hHw : ∀ w : E, H w = ∑ j, (b.repr w j * (ev j : 𝕜)) • b j := by
    intro w
    conv_lhs => rw [← b.sum_repr w]
    rw [map_sum]
    apply Finset.sum_congr rfl
    intro j _
    rw [map_smul, hv j, smul_smul]
  -- coordenadas de vetores do kernel fora de z são nulas
  have hker_coord : ∀ w ∈ H.ker, ∀ i, i ∉ z → b.repr w i = 0 := by
    intro w hw i hi
    have hevi : ev i ≠ 0 := fun h0 => hi ((hzmem).2 h0)
    have hw0 : H w = 0 := by rwa [LinearMap.mem_ker] at hw
    have hc : b.repr (H w) i = b.repr w i * (ev i : 𝕜) := by
      rw [hHw w, map_sum, Finset.sum_eq_single i]
      · rw [map_smul]
        have hbi : b.repr (b i) i = 1 := by
          rw [b.repr_apply_apply, hb_inner i]      -- candidato: repr_apply_apply
        rw [hbi]
        simp
      · intro j _ hji
        rw [map_smul]
        have hbj : b.repr (b j) i = 0 := by
          rw [b.repr_apply_apply, b.orthonormal.2 (Ne.symm hji)]
        rw [hbj]
        simp
      · intro h
        exact absurd (Finset.mem_univ i) h
    have h0 : b.repr w i * (ev i : 𝕜) = 0 := by
      rw [← hc, hw0]
      simp
    rcases mul_eq_zero.1 h0 with h | h
    · exact h
    · exfalso
      exact hevi (by exact_mod_cast h)
  -- (F2) kernel vive no span de z
  have hF2 : ∀ w ∈ H.ker, w = ∑ i ∈ z, b.repr w i • b i := by
    intro w hw
    conv_lhs => rw [← b.sum_repr w]
    rw [Finset.sum_subset (Finset.subset_univ z)]
    intro i _ hi
    rw [hker_coord w hw i hi]
    simp
  -- (1) a soma truncada está no kernel
  have hQker : ∀ y : E, (∑ i ∈ z, b.repr y i • b i) ∈ H.ker := by
    intro y
    apply Submodule.sum_mem                    -- candidato: Submodule.sum_mem
    intro i hi
    apply Submodule.smul_mem
    rw [hF1 i]
    exact (hzmem).1 hi
  -- interseção kernel/cokernel é zero
  have hbot : ∀ {w : E}, w ∈ H.ker → w ∈ (H.ker)ᗮ → w = 0 := by
    intro w hw hw'
    have h0 : ⟪w, w⟫_𝕜 = 0 := by
      have := hw' w hw                        -- defeq de (·)ᗮ; candidato: Submodule.mem_orthogonal
      exact this
    exact inner_self_eq_zero.1 h0              -- candidato: inner_self_eq_zero
  -- (2) o resto é ortogonal ao kernel
  have hQorth : ∀ y : E, y - (∑ i ∈ z, b.repr y i • b i) ∈ (H.ker)ᗮ := by
    intro y
    intro w hw                                -- defeq de (·)ᗮ; candidato: antes rw [Submodule.mem_orthogonal]
    rw [hF2 w hw, sum_inner]                  -- candidato: sum_inner
    apply Finset.sum_eq_zero
    intro i hi
    rw [inner_smul_left]                      -- candidato: inner_smul_left
    have hterm : ⟪b i, y - (∑ j ∈ z, b.repr y j • b j)⟫_𝕜 = 0 := by
      rw [inner_sub, inner_sum]               -- candidato: inner_sum
      rw [Finset.sum_eq_single_of_mem i hi]
      · simp_rw [inner_smul_right]
        rw [hb_inner i]
        rw [← b.repr_apply_apply, sub_self]   -- candidato: repr_apply_apply
      · intro j hj hji
        rw [inner_smul_right, b.orthonormal.2 (Ne.symm hji)]
        simp
    rw [hterm]
    simp
  -- unicidade da decomposição ortogonal
  have huniq : ∀ {y u : E}, u ∈ H.ker → y - u ∈ (H.ker)ᗮ → (H.ker).starProjection y = u := by
    intro y u hu hv
    have h1 : u - (H.ker).starProjection y ∈ H.ker :=
      (H.ker).sub_mem hu (Submodule.starProjection_mem y)        -- candidato: starProjection_mem
    have h2 : u - (H.ker).starProjection y ∈ (H.ker)ᗮ := by
      have heq : u - (H.ker).starProjection y
          = (y - (H.ker).starProjection y) - (y - u) := by abel
      rw [heq]
      exact (H.ker)ᗮ.sub_mem
        (Submodule.sub_starProjection_mem_orthogonal y) hv       -- candidato: sub_starProjection_mem_orthogonal
    have h0 := hbot h1 h2
    exact (sub_eq_zero.1 h0).symm
  -- (F3) a projeção é a soma truncada (reading defeq starProjection nas fontes)
  have hP : ∀ y : E, reading H y = ∑ i ∈ z, b.repr y i • b i := by
    intro y
    have h := huniq (hQker y) (hQorth y)
    exact h                                    -- candidato: defeq reading ↔ starProjection
  -- expansão do fluxo na base (reuso de T_apply_eigen)
  have hT : T H s x = ∑ j, (b.repr x j * ((Real.exp (-(s * ev j)) : ℝ) : 𝕜)) • b j := by
    conv_lhs => rw [← b.sum_repr x]
    rw [map_sum]
    apply Finset.sum_congr rfl
    intro j _
    rw [map_smul, T_apply_eigen H (ev j) (b j) (hv j) s, smul_smul]
  have hcoord : ∀ v i, b.repr v i = ⟪b i, v⟫_𝕜 := fun v i => b.repr_apply_apply v i
  have hcoordT : ∀ i, b.repr (T H s x) i
      = b.repr x i * ((Real.exp (-(s * ev i)) : ℝ) : 𝕜) := by
    intro i
    rw [hcoord, hT, inner_sum, Finset.sum_eq_single i]
    · rw [inner_smul_right, hb_inner i, ← hcoord]
      simp
    · intro j _ hji
      rw [inner_smul_right, b.orthonormal.2 (Ne.symm hji)]
      simp
    · intro h
      exact absurd (Finset.mem_univ i) h
  have hcoordP : ∀ i, b.repr (reading H x) i = if i ∈ z then b.repr x i else 0 := by
    intro i
    rw [hcoord, hP x, inner_sum]
    by_cases hi : i ∈ z
    · rw [if_pos hi, Finset.sum_eq_single_of_mem i hi]
      · rw [inner_smul_right, hb_inner i, ← hcoord]
        simp
      · intro j hj hji
        rw [inner_smul_right, b.orthonormal.2 (Ne.symm hji)]
        simp
    · rw [if_neg hi]
      apply Finset.sum_eq_zero
      intro j hj
      have hne : i ≠ j := by
        intro h
        subst h
        exact hi hj
      rw [inner_smul_right, b.orthonormal.2 hne]
      simp
  have hcoordDiff : ∀ i, b.repr (T H s x - reading H x) i
      = b.repr x i * ((Real.exp (-(s * ev i)) : ℝ) : 𝕜)
        - (if i ∈ z then b.repr x i else 0) := by
    intro i
    simp only [map_sub, Pi.sub_apply, hcoordT, hcoordP]   -- candidato: Pi.sub_apply
  have hcoordDiffX : ∀ i, b.repr (x - reading H x) i
      = if i ∈ z then (0 : 𝕜) else b.repr x i := by
    intro i
    by_cases hi : i ∈ z
    · rw [if_pos hi]
      simp only [map_sub, Pi.sub_apply, hcoordP]
      rw [if_pos hi]
      simp
    · rw [if_neg hi]
      simp only [map_sub, Pi.sub_apply, hcoordP]
      rw [if_neg hi]
      simp
  -- núcleo da cota, coordenada a coordenada (SEM triangular: constante 1 preservada)
  have hcore : ∀ i, ‖b.repr (T H s x - reading H x) i‖ ^ 2
      ≤ (Real.exp (-(s * γ))) ^ 2 * ‖b.repr (x - reading H x) i‖ ^ 2 := by
    intro i
    rw [hcoordDiff i, hcoordDiffX i]
    by_cases hi : i ∈ z
    · rw [if_pos hi, if_pos hi]
      have hevi : ev i = 0 := (hzmem).1 hi
      rw [hevi]
      simp                                     -- candidato: fecha via Real.exp_zero
    · rw [if_neg hi, if_neg hi]
      have hge : γ ≤ ev i := by
        rcases hgap i with h0 | hge
        · exfalso
          exact hi ((hzmem).2 h0)
        · exact hge
      have hexp : Real.exp (-(s * ev i)) ≤ Real.exp (-(s * γ)) := by
        apply Real.exp_le_exp.2                -- candidato: monotonicidade de exp
        rw [neg_le_neg_iff]
        exact mul_le_mul_of_nonneg_left hge hs
      have hnrm : ‖b.repr x i * ((Real.exp (-(s * ev i)) : ℝ) : 𝕜)‖
          = ‖b.repr x i‖ * Real.exp (-(s * ev i)) := by
        rw [norm_mul, RCLike.norm_ofReal,      -- candidato: RCLike.norm_ofReal
          abs_of_nonneg (Real.exp_nonneg _)]
      rw [sub_zero, hnrm, mul_pow, mul_pow,
        mul_comm ((Real.exp (-(s * γ))) ^ 2) _]
      exact mul_le_mul_of_nonneg_left
        (pow_le_pow_left (Real.exp_nonneg _) hexp _) (sq_nonneg _)
  have hsum : (∑ i, ‖b.repr (T H s x - reading H x) i‖ ^ 2)
      ≤ (Real.exp (-(s * γ))) ^ 2 * ∑ i, ‖b.repr (x - reading H x) i‖ ^ 2 := by
    rw [Finset.mul_sum]
    exact Finset.sum_le_sum fun i _ => hcore i

      = Real.sqrt (∑ i, ‖b.repr (T H s x - reading H x) i‖ ^ 2) := by
        rw [← b.repr.norm_map (T H s x - reading H x)]   -- candidato: LinearIsometryEquiv.norm_map

          * ∑ i, ‖b.repr (x - reading H x) i‖ ^ 2) :=
        Real.sqrt_le_sqrt hsum                            -- candidato: Real.sqrt_le_sqrt
    _ = Real.exp (-(s * γ)) * ‖x - reading H x‖ := by
        rw [Real.sqrt_mul (sq_nonneg _), Real.sqrt_sq (Real.exp_nonneg _),
          ← b.repr.norm_map (x - reading H x), EuclideanSpace.norm_eq]
