## 1. Recorrência escalar

O ansatz `(4πt)⁻² e^{−r²/4t} u(t,r)` na EDP do calor em coordenadas geodésicas radiais (`Δ = ∂_r² + 3(f′/f)∂_r`, `f = sin(√K r)/√K`) dá a equação de transporte verificada no CAS (`check('transport_from_heat_PDE', …)`):

$$\dot u = u'' + A_r u' - \frac{r u'}{t} - \frac{A_r r - 3}{2t}u$$

com $A_r = 3f'/f$. Para $u = u_0(1 + t\,a_1 + t^2 a_2 + \cdots)$:

- **$u_0 = (r/f)^{3/2} = 1 + Kr^2/4 + 19K^2r^4/480 + \cdots$** — resolve $r u_0' + (A_r r - 3)u_0/2 = 0$ ✓ (check no código).
- **Recorrência**: $r\,a_j' + j\,a_j = u_0^{-1}\Delta(u_0 a_{j-1})$ ✓ (verificada ordem a ordem).

Resultados escalar (todos `check` no CAS):
$$a_1(0) = 2K \qquad u_1(0) = 2K, \quad u_1 = 2K + \tfrac{29K^2 r^2}{60} + \cdots$$
$$a_2(0) = u_2(0) = \tfrac{1}{2}\Delta u_1\big|_0 = \frac{29K^2}{15}$$

A verificação independente fecha: em 4D, $\Delta g(0) = 8g_2$ para $g = g_0 + g_2 r^2 + \cdots$, logo $\Delta u_1(0) = 8 \cdot 29K^2/60 = 58K^2/15$, e $u_2(0) = 29K^2/15$. Este é também o $a_4$ de Seeley–DeWitt para escalar em espaço-forma: $\frac{1}{360}(5R^2 - 2R_{ij}R^{ij} + 2R_{ijkl}R^{ijkl})$ com $R = 12K$, $R_{ij}R^{ij} = 36K^2$, $R_{ijkl}R^{ijkl} = 24K^2$ dá exatamente $696K^2/360 = 29K^2/15$. ✓

## 3. Contribuição quadrática da conexão

Em gauge radial, $A_\mu = \frac{1}{2}x^\nu \Omega_{\nu\mu} + O(x^2)$. Então:

$$\mathrm{tr}\sum_\mu A_\mu^2 = \frac{1}{4}\sum_{\mu\nu\rho} x^\nu x^\rho\,\mathrm{tr}(\Omega_{\nu\mu}\Omega_{\rho\mu})$$

isto é quadrático em $x$. O Laplaciano 4D dá $\Delta(x^\nu x^\rho) = 2\delta^{\nu\rho}$, logo:

$$\Delta\!\left(\mathrm{tr}\sum A_\mu^2\right) = \frac{1}{2}\sum_{\mu\nu}\mathrm{tr}(\Omega_{\nu\mu}^2)$$

Portanto $\Delta(\mathrm{tr}\sum A^2)/6 = \mathrm{tr}\sum\Omega^2/12$. **O código verifica esta identidade** (`check(label+'_connection_transport', value − omega_trace/12)`) para ambas as fibras, construindo os $\Omega_{\nu\mu}$ explicitamente e comparando com resultados anteriores (`metric_connection_previous_trace`, `ghost_connection_previous_trace`). ✓

**Contribuição à conexão ao peso**: $(\frac{1}{2})(-12K^2) - (-2K^2) = -4K^2$, corretamente citada. O controle negativo `discard_connection_contribution` **reprova** (o termo é não-nulo). ✓

## 5. Convenção e pesos dos determinantes

**Convenção** $D = -(\nabla^2 + E)$: o kernel de calor é $e^{-tD} = e^{t(\nabla^2 + E)}$. Com $E$ paralelo, a fatorização dá o sinal **positivo** de $\mathrm{tr}\,E^2/2$ no $a_4$ (consistente com o código). A divergência de $\mathrm{tr}\,\log D$ em 4D é proporcional a $-\mathrm{tr}\,a_4$.

**Pesos**: $\Gamma_1 = \frac{1}{2}\mathrm{Tr}\log D_m - \mathrm{Tr}\log D_g$ — padrão Faddeev–Popov (métrica real simétrica: peso $\frac{1}{2}$; ghost complexo: peso $-1$). Verificado no código:
- Peso de rank: $\frac{1}{2}(10) - 4 = 1$ ✓
- Peso de $a_2$: $\frac{1}{2}(20K - 12K) - (8K + 12K) = -16K$ ✓
- Controle negativo `incorrect_determinant_ghost_weight` reprova sinal errado ✓

## 6. Cálculo final do coeficiente

| fibra | rank | $\mathrm{tr}\,E$ | $\mathrm{tr}\,E^2$ | $\mathrm{tr}\,\Omega^2$ | $\mathrm{tr}\,a_4$ |
|---|---:|---:|---:|---:|---:|

| $T^*$ ghost | 4 | $12K$ | $36K^2$ | $-24K^2$ | $716K^2/15$ |

Verificação independente de cada célula:
- $S^2T^*$: $10 \cdot \frac{29K^2}{15} + 2K(-12K) + \frac{72K^2}{2} + \frac{-144K^2}{12} = \frac{290}{15}K^2 - 24K^2 + 36K^2 - 12K^2 = \frac{290}{15}K^2 = \frac{58}{3}K^2$ ✓

**Peso**:
$$\frac{1}{2} \cdot \frac{58K^2}{3} - \frac{716K^2}{15} = \frac{145K^2}{15} - \frac{716K^2}{15} = \boxed{-\frac{571K^2}{15}}$$
