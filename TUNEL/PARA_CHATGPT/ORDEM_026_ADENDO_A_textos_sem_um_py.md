## 2. A regra do DOI

O https://doi.org/10.5281/zenodo.23649800 responde **302** para `https://zenodo.org/doi/10.5281/zenodo.23649800`, e a API do registro (`https://zenodo.org/api/records/23649800`) responde **200**. O **403** da página HTML do Zenodo é o bloqueio dele a acessos automatizados, não um link quebrado (num navegador a página abre). Para este link, a conferência de «HTTP 200» do §1.4 passa a ser: o doi.org responde 302 com destino no zenodo.org **e** a API do registro responde 200. Os outros links seguem a regra do 200.
