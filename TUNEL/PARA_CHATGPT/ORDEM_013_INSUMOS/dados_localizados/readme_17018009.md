# Data Release for "Black Hole Spectroscopy and Tests of General Relativity with GW250114"

This repository contains data products, results, and scripts associated with the LIGO, Virgo, and KAGRA collaboration paper "Black Hole Spectroscopy and Tests of General Relativity with GW250114" (https://dcc.ligo.org/LIGO-P2500461/public).  

## Layout

Various directories contain results and data products from different analyses presented in the paper.  There are also:

- `scripts/`: scripts used to make paper figures and process data.
- `figures/`: figure output from the scripts goes here.
- `macros/`: TeX macros used for various quantities in the paper, generated by the scripts, goes here.

There is a [uv](https://docs.astral.sh/uv/) environment suitable to run the scripts as well, represented in the files `pyproject.toml` and `uv.lock`.

All scripts read their inputs starting from `directories.basedir`, a `Path` object defined in `scripts/directories.py`.  You should adjust this to point to the top-level directory where you have placed this repository on your system before running the scripts; once this is adjusted, all data should load and outputs should be written to the appropriate places when various scripts are run.
