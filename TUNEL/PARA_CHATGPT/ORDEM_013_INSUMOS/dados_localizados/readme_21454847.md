This is the data release for the paper GWTC-5.0: Tests of General Relativity. Included are the data products necessary to reproduce the figures in the paper using results from the following ananalysis pipelines:

- FTI_TIGER: Flexible Theory-Independent test / Test Infrastructure for GEneral Relativity post-inspiral analysis
- POL: test for non-GR polarizations
- pSEOB: full-signal parameterized ringdown test of BBH merger remnants
- QNMRF: Quasi-Normal Mode Rational Filter (ringdown test of BBH merger remnants)
- RD: post-merger ringdown test of BBH merger remnants
- RES: residual test

The `.tar.gz` file associated with each analysis contains the data required to run the plotting scripts/notebooks and specific plotting environments where necessary, alongside a README file with instructions.
